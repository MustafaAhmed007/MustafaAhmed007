# Security Policy

## Supported versions

The `main` branch is the supported version.

## Reporting a vulnerability

Please do not disclose exploitable details in a public issue. Contact the repository owner privately through the public contact address listed in the profile README and include:

- affected file or component
- reproduction steps
- expected vs. actual behavior
- impact assessment, if known

Do not include secrets, access tokens, passwords, or other sensitive credentials in a report.
